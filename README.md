Zero One Legacy — Landing Page
Landing page VIP group Zero One Legacy (chart trading animasi, tema hitam & emas).

Menjalankan lokal
npm install
npm start
Deploy ke Railway
Push folder ini ke GitHub (lihat langkah di bawah).
Buka https://railway.app → New Project → Deploy from GitHub repo.
Pilih repo ini. Railway akan otomatis mendeteksi package.json dan menjalankan npm install && npm start.
Setelah deploy selesai, klik Generate Domain di tab Settings untuk mendapatkan URL publik.
Push ke GitHub
git init
git add .
git commit -m "Landing page Zero One Legacy"
git branch -M main
git remote add origin https://github.com/USERNAME/NAMA-REPO.git
git push -u origin main
Ganti USERNAME/NAMA-REPO dengan repo GitHub Anda.
